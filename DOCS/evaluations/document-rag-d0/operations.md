# Cedar operations handbook — synthetic evaluation source

## Intake

Each incident receives a case identifier before triage. The intake coordinator
owns this step. The coordinator must record the affected service and observed
start time. This handbook does not specify an incident-reporting telephone number.

## Escalation

The on-call analyst classifies the incident using the service-level table.
An urgent incident goes to the duty manager within 15 minutes of classification.
A standard incident goes to the queue owner within 2 hours of classification.
The clock starts at classification, not when the user first reports the issue.

## Closure

The duty manager approves closure for urgent incidents. The queue owner approves
closure for standard incidents. Approval and the recovery time are recorded in
the case log. Closing a case does not shorten its retention period.
