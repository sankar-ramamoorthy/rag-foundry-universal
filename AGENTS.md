# AGENTS.md

This file exists so any agent (Codex, etc.) that looks for `AGENTS.md`
instead of `CLAUDE.md` finds the same guidance.

**Read `CLAUDE.md` in this same directory — it is the single source of
truth for working in this repository.** Everything else (architecture,
build/test/lint commands, dependency management, the data model, coding
workflow, documentation map) is documented there and in `DOCS/index.md`;
this file does not duplicate it, to avoid the two drifting apart.
